# 新聞記者文章彙整器

這是一個可自行部署的新聞彙整頁面原型，已放入你提供的所有來源網址。

## 功能
- 將指定作者／記者／關鍵字搜尋頁面的文章連結集中到單一頁面
- 標題、來源、連結、首次抓取時間
- 標題搜尋、來源篩選
- 啟動時先抓一次
- 背景每 1 小時自動抓取一次
- SQLite 去重，避免同一篇文章重複出現

## 啟動
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
瀏覽 `http://localhost:5000`

## 部署注意
部分新聞網站可能有 robots.txt、反爬、JavaScript 渲染或付費牆，因此同一套抓取規則不一定能完整取得所有站點。
正式上線建議改成：
1. 優先使用各站 RSS/API（若有）
2. 各站建立專用 parser
3. 用 cron/systemd 每小時執行抓取
4. 網頁只顯示標題、時間、來源與原文連結，避免重製受版權保護的全文

目前版本是「通用原型」，適合先確認介面與資料流，再針對各媒體做精準解析。
